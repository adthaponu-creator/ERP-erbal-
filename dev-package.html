──── สรุป 4 Audit Items ที่ต้องแก้ ────

#1 Sample Plan Trigger [HIGH]
   → ปัญหา: ไม่มีแจ้งเตือนเมื่อ lot รับเข้า/WO complete ต้องสร้าง QC entry manual
   → แก้: เพิ่ม Pending QC Tasks panel + 4 auto-triggers (gr/wo/stability/complaint)

#3 Retain Sample Storage [MEDIUM]
   → ปัญหา: ไม่มีคลังเก็บ retain sample
   → แก้: เพิ่ม 4 warehouses (Retain rooms + Stability chambers) + storage fields

#6 Dual Approval [CRITICAL]
   → ปัญหา: ปุ่ม Released ใครก็กดได้ ไม่มีการตรวจนับก่อนปล่อยเข้าคลัง
   → แก้: แยก Released เป็น 2 ขั้น — QC Released → Warehouse Verified (RBAC)

#7 Auto-notification [HIGH]
   → ปัญหา: ไม่มีแจ้งเตือนข้ามฝ่ายเมื่อ stage เปลี่ยน
   → แก้: เพิ่ม Bell icon + Toast + WebSocket real-time (8 event types)

──── ลำดับ implement ที่แนะนำ ────

1. #7 Notification system (เป็น dependency ของ #1 และ #6)
2. #1 Sample Plan Trigger
3. #6 Dual Approval
4. #3 Retain Sample (ทำคู่ขนานได้)
