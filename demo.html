🧪 วิธีทดสอบ Flow (แนะนำ)

  1. เปิด หน้าสร้าง IPC Criteria → สร้าง IPC-CAP-TARE-001 (Multi-Point Numeric, 10 จุด, Aggregate = Mean) → กด CREATE
  2. หลังกด CREATE → Modal ขึ้น → กด "+ สร้าง Criteria ตัวใหม่"
  3. กรอก IPC-CAP-WV-001 (Weight Variation, Multi-Point, 20 จุด, Target 0.500, Tolerance 7.5%) → ในส่วน "⚖️ หัก Tare" เลือก IPC-CAP-TARE-001 → CREATE
  4. หลัง CREATE → Modal ขึ้น → กด "👷 ไปหน้าบันทึกผล"
  5. คลิกการ์ด IPC-CAP-TARE-001 → กรอก 10 ค่า (เช่น 0.0958, 0.0962, ...) → กดส่งผล
  6. กลับ list → คลิกการ์ด IPC-CAP-WV-001 → ดู Tare banner สีฟ้าด้านบน → กรอก Gross weight 20 ค่า → เห็น Net คำนวณให้
  7. กลับ list → กด "+ รอบใหม่" บนการ์ด WV-001 → กรอกเหตุผล → ลองบันทึกอีกรอบ

✨ Key Features ที่ Prototype สาธิต

✓ 9 Criteria Types — Numeric, Pass/Fail, Visual, Text, Multi-Point, Custom Multi-Field, Calibration, Tare, Calculated
✓ Smart Auto-fill — เลือก Test Name → เติม Code/Unit/Sample Plan
✓ Multi-Stage Acceptance — USP <711>, <905>, <701>
✓ Multi-Trigger Inspection — Time/Quantity/Milestone/Event/Once-per-batch

✓ Searchable Dropdowns — keyboard navigation (↑↓ Enter Esc)
