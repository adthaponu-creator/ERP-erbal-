Herbal ERP — QC Module

Quality Control: ลงทะเบียนตัวอย่าง → ทดสอบ → Release lot

Prototype สำหรับ QC Workflow — รับตัวอย่างจาก production / supplier / stability → ทดสอบตาม test panel มาตรฐาน → QA review → Release / Reject / OOS

🗺 QC Flow Overview

STEP 1
QC Sampler / QA
📥
รับตัวอย่าง + ขอเบิก
  1. เลือกประเภทแหล่งที่มา
  2. เลือกสินค้า + Lot กักกัน
  3. กำหนด test panel + ตัด stock
STEP 2
Lab Technician
🔬
ทดสอบ Test Panel
  1. ยืนยัน sampling → ตัด stock
  2. บันทึกผลทุก test live
  3. จัดการ OOS ถ้าเจอ
STEP 3
QA Reviewer
✅
Submit → Release
  1. QA ตรวจสอบผลรวม
  2. ออก CoA
  3. Release lot → พร้อมขาย

→
④ Approved
